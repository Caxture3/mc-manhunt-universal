# 蛮兵开关、跨局选队与重启续局

## 禁用猪灵蛮兵

`disable-piglin-brutes` 默认为 `false`，可通过配置列表点击切换，或执行：

```text
/mhu config disable-piglin-brutes true
```

仅正式 RUNNING 游戏期间生效。开启时立即清除当前已加载世界中的猪灵蛮兵，同时阻止生成；包含后续载入区块中的现存蛮兵。清除使用实体移除，不产生死亡掉落或经验。普通猪灵不受影响，空闲和倒计时不限制，关闭后允许正常生成；已移除实体不会重新生成回来。

API 功能 ID 为 `core:piglin-brute-suppression`，扩展可通过功能策略接管核心限制；配置自身也支持 API 1.1 的锁定与覆盖。

## 跨对局保留选队

正式结算、管理员停止或倒计时取消后，玩家先前明确选择的 hunter/runner 继续保留，包括速通者预约顺序，并恢复相应 Tab/名称牌预览。随机抽到的实际身份不会自动成为下一局的预约。

保留范围是本次服务器运行。玩家退出仍清除其选择，重连需要重新选择；服务器重启不保存开局前预约。`join random` 仍清除当前选择，强制随机开关仍立即清空全部预约。

如果活动局内调低了速通者人数，本局不受影响，也不会发容量清除通知；回到空闲后按新上限从最后预约的玩家开始清除超额选择。下一局仍优先纳入明确速通者，仅从 random 补足，候选不足则拒绝开局。

## 服务器重启续局

插件在 `plugins/ManhuntUniversal/runtime-state.yml` 保存核心续局快照，使用临时文件和原子替换。每 100 tick（正常 20 TPS 下约五秒）保存检查点，正常关闭前再保存最新状态。正式停止或结算会立即保存“无活动局”，避免下次恢复已经结束的游戏。

保留内容包括：

- 当前倒计时或正式游戏、原会话 UUID/修订、参与者、角色和逐人淘汰状态。
- 剩余倒计时、正式开始时间和历史时间轴、已绑定末地（包括猎人末地解锁）。
- 本局冻结的速通者人数、开局重置开关及定位参数，和当前追踪选择、各维度最后位置。
- 离线玩家待执行的开局重置、原失明效果、淘汰前游戏模式、Tab 名称恢复记录。

**停服时间不计入对局或结构解锁倒计时。** 启动时载入原角色，下一 tick 恢复运行任务；倒计时继续剩余秒数，正式游戏恢复指南针、身份显示和末地检查。已经 RUNNING 的游戏不会重新清背包、传送、重新抽角色或重复显示开局标题。原生定位结果和缓存重新建立，第一次追踪仍可能需要查询。

离线玩家不因此被判死；淘汰者回服继续旁观，结算或停止后恢复原模式。所有参与者尚未登录时，对局仍保留。背包、方块、实体、世界和玩家位置仍由 Minecraft 服务器正常保存，插件不会复制整份世界存档。

恢复沿用同一会话 ID，提供给扩展的注册句柄、菜单授权和异步定位请求均重新生成。旧客户端界面不能凭先前按钮继续修改当前菜单。自定义追踪目标重新检查注册、角色和可用性；扩展缺失或目标已禁用时清除该选择。

## 存档错误与扩展职责

快照有格式版本、完整值校验和 8 MiB 文件上限。损坏或不兼容文件不会部分载入或自动覆盖；服务器日志会报告错误，并暂停后续自动保存。需先备份并修复该文件，或移走文件以放弃续局，然后重启插件/服务器；不要在对局运行时手改快照。普通写入失败会保留上次成功的检查点并记录错误。

本功能面向正常 `/stop` 关服和重启。定期检查点不能保证强制断电、磁盘故障或进程崩溃时世界文件与插件快照处于完全相同的一刻，不提供跨文件回滚事务。备份服务器时应一起备份世界、玩家数据、配置和续局文件。

扩展自己的调度任务、临时数据、回调、注册和储存仍由扩展负责恢复。核心不序列化这些对象；扩展可在 `onEnable()` 获取 API 当前对局，结合自己的持久化数据重新注册能力、恢复任务。恢复 RUNNING 不重发“新游戏开始”事件；恢复倒计时在真正开始时正常发布开始事件。
