# 扩展 API 1.1 标准：配置、文本与显示控制

状态：已确认并保存，暂不实施。保存日期：2026-10-31。

## 1. 总体设计与兼容

保留 API 1.0 的对局、角色、淘汰和策略接口，新增配置、文本和显示三个入口，SDK 升级为 **1.1.0**，保持已有扩展的兼容性。

工作方式统一为：**扩展注册能力 → 核心在对应环节调用 → 扩展修改、替换或取消 → 核心执行并负责恢复**。

- 新能力继续绑定现有扩展注册句柄；允许单独撤销，扩展停用时自动释放。
- 文本、配置有效值和显示替换按显式优先级选取处理者；同优先级的重复替换报冲突。
- 追加内容允许组合，按优先级及扩展 ID 稳定排序。
- 同一核心功能同一时刻只执行一个接管者，避免核心与扩展重复产生效果。
- 纯数据和配置合同放在 `api`；Adventure 组件、Paper 显示与事件合同放在 `api-paper`。

## 2. 配置注册与效果接管

新增 `ConfigurationRegistry`，支持注册配置、查询状态、修改值、锁定以及接管。

- 配置键使用命名空间，例如 `rotation:interval`；核心现有短名称保持可用。
- 提供布尔、整数、小数、文本、枚举、字符串列表类型，并允许扩展提供自定义解析、校验和补全。
- 注册时提供本地化名称、说明、默认值、取值限制和读写委托。**扩展负责保存自己的配置**，核心提供统一界面和操作流程。
- 新配置进入 `/mhu config`；布尔项点击切换，其他项预填命令并提供适当补全。
- 锁定项仍显示，标明接管者和原因；命令、旧点击按钮及其他写入口均重新检查锁定状态。
- 区分保存值与当前有效值；两者不同时，在查询中明确显示。

效果控制分为两类：

1. **有效值覆盖**：为人数、距离、冷却等参数提供经过校验的替代值。
2. **功能接管**：暂停对应核心处理，由扩展执行，例如使用自己的矿物掉落算法。

核心现有配置均接入明确的参数或功能适配入口。继续遵守原有“即时生效／下一局生效”和 RUNNING 限制；修改人数不会隐式重分配已锁定角色。

保存委托报告成功后才触发生效流程；失败不得执行核心副作用。扩展负责其存储操作的原子性，回调异常由核心隔离并明确报告。

## 3. 运行时文本覆盖

新增 `TextRegistry`，支持覆盖内置文本、注册扩展语言键和提供动态占位符。

- 覆盖范围包括前缀、角色显示名称、配置说明、标题、提示和结算文案。
- 支持中英文及按接收者生成文本；角色显示名称的修改不改变实际角色判定。
- 解析顺序为：**当前生效的扩展覆盖 → 服务器外部语言文件 → 内置语言回退**。
- 保留现有文本格式；富文本、点击和悬停内容通过 Paper 的 Adventure 组件接口提供。
- 覆盖只存在于运行时，不改写现有语言文件；撤销后重新使用原有解析结果。

## 4. 全部服务端显示与逐观察者身份

新增 `PresentationRegistry`。核心产生的聊天、标题、副标题、Actionbar、Tab、Nametag、指南针名称与说明、Paper 菜单及声音均经过统一显示入口。

显示请求携带稳定标识、通道、接收者及相关对局快照。扩展可修改内容、替换整个输出、取消输出或主动请求刷新。

**结算采用结构化内容：**

- 提供不可变 `ResultSnapshot`，包含胜方、原因、时间、参与者及最终状态等数据。
- 支持追加带独立 ID 的结算区块、调整区块顺序和显隐。
- 允许最高优先级渲染器完全替换聊天结算、标题和声音。
- 修改或取消结算显示，不改变实际判胜和清理流程；默认仍不展示轮次历史。

**隐藏规则：**

- 普通文本覆盖和内容追加继续遵守 `hide-role-assignments`。
- 扩展明确声明接管角色可见性后，才允许覆盖角色显示开关。
- 此规则约束通过核心显示接口产生的内容。

**逐观察者身份显示：**

- 显示提供者接收“观察者＋目标玩家”上下文。
- Tab 支持独立文本、显隐和排序；Nametag 支持前后缀、颜色和显隐，保留真实玩家名。
- 核心自带两版的数据包适配，不增加必装协议插件；版本差异放在对应版本模块。
- 不替换其他插件的侧边栏；处理玩家加入、退出、重连、角色变化及原有显示更新。
- 扩展撤销或停用时恢复当前应有的显示，避免旧缓存重新覆盖新状态；适配异常不得静默降级为公开隐藏身份。

Fabric 专用界面的内容与通信协议维持现状；扩展可以取消核心打开该界面的请求，或选择使用可定制的 Paper 菜单。

## 5. 生命周期、验证与交付

- 配置定义、锁定、覆盖及渲染器均有独立释放句柄，并随所属扩展注销。
- 核心主线程执行委托；网络适配只使用已计算的显示快照，不在网络线程调用扩展逻辑。
- 保留现有重入保护；显示取消不能阻止必要的对局清理和身份恢复。
- 测试配置保存失败、锁定旧按钮、有效值切换、功能接管、优先级冲突、异常隔离及停用恢复。
- 测试文本回退、隐藏规则、结算追加与替换，以及两名观察者看到不同 Tab/Nametag 后的重连和恢复。
- 验证旧 API 1.0 扩展继续使用现有能力；分别构建两个 Minecraft 版本，核对 SDK、部署 JAR 和校验和。
- 更新开发者指南，提供配置注册、功能接管、文本覆盖、结算扩展和逐观察者显示示例。延续精简验证，不运行完整游戏测试，并单独记录尚未进行的实服显示验证。
