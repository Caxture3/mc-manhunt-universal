# 角色分配与显示开关

目标：两个独立的布尔配置均默认 false，沿用双版本共享实现和现有配置交互。

- `force-random-roles`：成功保存 true 后立即清空所有预约、恢复预约颜色，停止登录提示，拒绝所有 join 入口并移除相关补全。已进入倒计时或运行的角色保持锁定。关闭后允许重新选队，不恢复旧选择。
- `hide-role-assignments`：保留选队及真实身份；不发送含具体选择的确认、开局速通者名单、status 双方名单或结算名单/击杀者。选队/缩容反馈用中性文本。开启时立即恢复 Tab/名称牌原显示，关闭时恢复当前预约/实际身份颜色，兼容离线恢复。
- 用户确认保留屏幕中央的个人身份标题；指南针、角色判定、胜负和协议保持不变。既有聊天消息不可撤回。
- 不改写服务器已有外部语言文件；新增内置双语键与手动更新说明。README 保持公开仓库形式。
