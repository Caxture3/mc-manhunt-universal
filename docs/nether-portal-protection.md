# 下界传送门保护

```yaml
prevent-nether-portal-destruction: false
```

默认关闭。启用后，仅在正式 RUNNING 游戏期间保护下界（Nether 环境）中的下界传送门，修改实时生效，对所有玩家生效，包含 OP、创造模式和局外玩家。主世界和末地不受限制；空闲、开局倒计时、结算及停止后不限制。

```text
/mhu config prevent-nether-portal-destruction true
/mhu config prevent-nether-portal-destruction false
```

可在 `/mhu config` 列表中点击“禁止在下界破坏传送门”切换；悬停显示内部键，沿用管理员权限和原子保存机制。

## 保护范围

- 门体及维持传送门有效的必要黑曜石边框，不保护可省略的四角、与门平面垂直的装饰黑曜石或普通黑曜石。
- 拦截玩家直接破坏、创造模式和多方块放置、玩家桶、发射器放置流体、流体流入、活塞推拉、实体改方块及物理销毁。
- 爆炸仅从受损列表中移除受保护的门体和门框，其他方块和爆炸效果继续处理。床、重生锚、TNT、苦力怕等走相同爆炸保护路径。
- 阻止自然变化、植物／结构生成和跨维度自动造门覆盖已有传送门；在空位置正常点燃或创建新门以及穿过门不受限制。

事件在变化发生前拦截，不进行每 tick 全世界扫描，也不靠反复恢复方块来补救。邻接区块未加载、无法确认门框时，对边界黑曜石保守保护，不为检查而强制加载区块。

本功能覆盖原版玩家与环境破坏。管理员直接替换方块的指令、WorldEdit 和其他插件直接修改方块不在保证范围内；这是已确认的开发范围。

## 外部语言文件

已有服务器语言文件不会自动改写。自定义时可手动合并：

- `config.name.prevent-nether-portal-destruction`
- `restriction.nether-portal-destruction-denied`

缺失时回退到插件内置双语文本，无需修改客户端模组或协议。
