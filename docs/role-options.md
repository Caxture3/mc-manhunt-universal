# 角色分配与显示配置

两项均为布尔值，默认 `false`，在现有配置列表中点击即可切换，也支持命令：

```text
/mhu config force-random-roles true
/mhu config hide-role-assignments true
```

| 强制随机 | 隐藏分配 | 结果 |
| --- | --- | --- |
| false | false | 允许选队，显示选队与实际角色。 |
| true | false | 不允许选队，全员随机；显示实际角色。 |
| false | true | 允许选队，选择照常影响开局；隐藏选择和实际分配的聊天、Tab、名称牌显示。 |
| true | true | 不允许选队，全员随机；隐藏分配的聊天、Tab、名称牌显示。 |

## 强制随机

`force-random-roles` 成功保存为 true 后立即清空所有预约并恢复预约颜色；服务器登录不再提示选队，`/mhu join`（包括不带参数、hunter、runner、random）全部拒绝，相关命令补全不再提供。旧消息中的选队按钮也无法绕过限制。

开局仍保留配置中的速通者人数，使用既有随机抽取逻辑，至少留一名猎人。已经开始倒计时或运行的对局保持锁定角色，不因切换开关而重新分配。关闭后允许重新选择，不恢复旧预约。

## 隐藏分配

`hide-role-assignments` 只控制显示，不清除预约，不改变角色、人数、胜负或开局抽取逻辑。仍可收到包含选项的选队菜单，但选队成功只显示中性的“已记录你的选择”，配置缩容也不显示原先选择的队伍。

- 不广播开局速通者名单。
- `/mhu status` 保留参与人数、时间、存活人数，隐藏双方名单；管理员与控制台同样适用。
- 结算显示胜方和原因，隐藏双方名单及击杀者，避免透露个人身份。
- Tab 列表与名称牌恢复插件着色前的显示，不添加角色颜色。
- 保留仅自己可见的开局个人身份标题、指南针、追踪界面与所有实际角色判定。

切换即时生效，包括空闲预约、倒计时和运行中。关闭隐藏后，当前预约或本局实际身份颜色重新显示；离线者重连时补恢复。已发送的旧聊天内容不会被撤回。

配置保存失败时不改变选队或显示。两个开关不互相启停；开启强制随机不会隐藏正式身份，开启隐藏也不会禁用选队。

## 语言文件维护

不会自动改写已有外部语言文件。可手动从内置语言资源合并以下新键；未合并时使用内置回退文本：

- `config.name.force-random-roles`
- `config.name.hide-role-assignments`
- `team.disabled`
- `team.selected-hidden`
- `team.capacity-cleared-hidden`
- `game.result.hidden-report`
