# 自定义开局位置世界与方向更新

2026-11-07，产品1.0.0、API/SDK1.2.0、协议3保持不变，无需更新Fabric逻辑。

自定义条目增加yaw/pitch并保留世界UUID与XYZ；配置列表显示 `(overworld: -31.0, 87.0, -12.0; 180.0°, 0.0°)`。添加/移除参数支持XYZ、可选的yaw/pitch和world，默认方向0 0、世界overworld；添加按钮预填消息生成时的完整位置，列表末尾不再显示下一局提示，冻结时机仍为NEXT_MATCH。
