# 离线玩家角色变更验证

2026-11-01，扩展 API 的 `roles().assign` 与 `roles().reroll` 已允许离线且未淘汰的参与者变更角色或参与抽签。公开方法签名保持不变，SDK 仍为 1.1.0，插件/模组仍为 0.2.0，协议仍为 3。

在线玩家仍需非死亡且无待执行的开局重置；淘汰者必须通过原有复活接口显式复活后才能改角色。换角不清除离线重置债务、不复活玩家、不重新计时或撤销末地解锁。重连按当前角色同步颜色、指南针和追踪权限；换角重建追踪状态时保留各维度已知位置，旧的结构选择和界面授权仍会清除。

## 检查结果

- 针对性 RED 阶段的四个离线分配案例按预期失败，修改后通过。
- 新增九项检查：离线指定分配及待重置债务/续局快照；变更事件中离线；提交前重连且待重置时原子拒绝；离线速通者被重抽为猎人及离线猎人被抽为速通者；全员离线抽签并固定淘汰者；重连颜色及原显示恢复；离线对象不读取过期死亡状态；在线死亡/待重置保护；已知位置重建与离线目标追踪。
- 分别执行 `build '-PmcVersion=1.21.11' --offline --console=plain` 和 `build '-PmcVersion=26.3' --offline --console=plain`，均通过。总计 591 项检查，Paper 每版 274 项；其他模块合计 43 项。
- 四个部署 JAR、六个 SDK JAR 及 `dist/SHA256SUMS.txt` 已更新并复核，SDK 源码/Javadoc 同步新合同。原 1.0 消费者字节码在最终 1.1.0 SDK 上仍能链接。135 个双语键/占位符、目标字节码及服务端/客户端隔离检查通过，`git diff --check` 通过。
