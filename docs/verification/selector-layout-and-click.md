# Fabric 追踪界面排版与点击修复

2026-11-07，产品1.0.0、SDK1.2.0、协议3保持不变。

提交 `71bcd49` 引入动态目标界面时，内置卡片改为显示服务端按接收者语言解析的名称，英文副标题来自枚举大写名称。此次改为客户端固定的双语标签：上方大字中文、下方小字英文，英文每词首字母大写且整行显示。动态界面和旧版兼容界面共用标签；扩展自定义目标继续显示其下发的名称。

26.3 原版 `InputConstants.MOUSE_BUTTON_LEFT` 为1，动态界面硬编码按键0导致左键选择、翻页无响应。两项操作现复用已有版本适配，1.21.11继续使用0；旧版兼容界面也使用同一主键判断。未放宽服务端对局、授权、目录修订号和解锁校验。

## 验证

- 提取原有动态点击判断后，26.3新增两项回归检查失败，确认主键无法选中普通目标和已解锁目标；改用版本适配后通过。
- 检查内置与扩展目标点击、非主键与画布外点击、任务锁定及计时解锁。两版各12项Fabric检查，全部模块共725项检查通过。
- 分别执行 `gradlew.bat build -PmcVersion=1.21.11 --offline --console=plain` 和 `gradlew.bat build -PmcVersion=26.3 --offline --console=plain`，两版构建成功。日志位于 `build/selector-fix/`。
- 核对两个Fabric部署JAR中的共享标签类、动态界面、元数据及Java21/25；更新 `dist/` 部署包和 `SHA256SUMS.txt`。机器检查报告为 `build/reports/selector-fix-artifacts.json`。

未运行真实客户端渲染、Dawn Client 联机点击或不同GUI缩放/语言的游戏内检查；编译和输入映射回归检查不替代这些运行验证。
